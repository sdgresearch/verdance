# Project Scope

- Verdance is a python package that computes green metrics on a given area of interest.
The initial goal of verdance is to compute the 3-30-300 rule using open source data, but it can be used with custom data, such as buildings or tree surveys.
- As new ways to quanitfy green spaces are developed, they will be added to the project.
- Verdance also enables the fast visualization of results with a map where metrics are displayed at the building level, as well as aggregated over user-provided geographies or standard polygons suchs as H3.
